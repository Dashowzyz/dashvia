# Dashvia

Site para organizar a vida financeira: acompanhe gastos, assinaturas e parcelas num só lugar, sozinho ou em um espaço compartilhado com outras pessoas. Funciona no navegador e pode ser instalado como app no celular e no computador (PWA).

**Site:** https://dashvia.app

## O que dá para fazer

- **Dashboard:** visão geral dos gastos do mês
- **Adicionar:** registrar novos gastos
- **Assinaturas:** controlar serviços recorrentes
- **Parcelas:** acompanhar compras parceladas
- **Histórico:** consultar meses anteriores
- **Espaço compartilhado:** dividir e acompanhar gastos com outras pessoas, com atualização em tempo real
- **Configurações:** ajustes da conta

## Instalar como app

- **Android (Chrome):** menu de três pontos > "Instalar app"
- **iPhone (Safari):** Compartilhar > "Adicionar à Tela de Início"
- **Computador (Chrome ou Edge):** ícone de instalar na barra de endereço

## Tecnologias

HTML, CSS e JavaScript puro, publicado pela Cloudflare.

## Estrutura

```
css/          estilos das páginas
js/           scripts do site
img/          logo e ícones do app
ferramentas/  scripts de apoio
*.html        páginas do site
manifest.webmanifest, sw.js   configuração do app instalável
```

## Rodar localmente

Abra a pasta no VS Code e use uma extensão de servidor local (como o Live Server) para abrir o `index.html`.
